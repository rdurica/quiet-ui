# QuietUI

Opinionated UI for WoW Forever. Modern and quiet: few frames, few buttons, text stays. The addon turns on or off, and one window chooses what stays visible.

## Product

- The goal is a clean UI, not a configurable framework.
- `/quiet` turns it on or off (`on` / `off`, no argument toggles). `/quiet setup` is the one window, with seven tabs: General, Visible, Bars, Groups, Player, Chat, and Info. Info holds a short description of QuietUI and how Glance works. General holds shared presets and their existing Edit Mode layouts, or Force QuietUI layout for <no preset> (missing means off). Check what stays visible, set which bars fade together, choose which bars stay up for an enemy or a friendly target, turn the player frame on or off, group buffs and debuffs with that frame (missing means on), keep debuffs always visible (missing means on), turn In range on or off, choose 10 yards, 28 yards, or Spell, type an optional spell name, and choose Unfriendly or Friendly, choose modern chat and how soon its lines fade, then Save, which leaves the window open. Reset default restores the rules below, turns force off, and saves immediately. Import layout writes the bundled Edit Mode layout right away, even after "Not now". The X and Escape close the window without saving. The window stays the size of the tallest tab, so switching tabs does not resize it. A minimap button opens that window. Left click opens it even while QuietUI is off. Drag moves it around the minimap.
- `QuietUIDB` is the account and may hold only `enabled`, the button position after dragging, `layoutHash` (the last answered layout version), `presets` (stable IDs to named shared settings and layout references), `nextPresetId` (monotonic ID counter), and `minimap` (degrees around the minimap for the setup button; a missing value sits at the bottom-left). The setup is per character in `QuietUICharDB`: `presetId` (missing means <no preset>), `previousLayoutRef` (name and type, or built-in identity, for restoring after layout reordering), `presetLayoutManaged` (a preset took over the layout; restore it even after detaching), and a personal snapshot of the settings: `visible` (HUD rows that stay on screen; excludes action bars and swing timer; a missing flag means off), `hoverOnly` (HUD rows that show only on hover; missing means off except XP, which defaults on unless Always visible is set; explicit false keeps normal XP rules), `groupVisibility` (numeric fade-group IDs to `"always"` or `"hover"`; missing means usual rules), `forceLayout` (`true` selects the QuietUI layout when the addon turns on and restores the previous one when it turns off; missing means off), `player` (`resource` keeps the portrait for edit mode; missing means on, beside the personal resource bar), `playerThresholdKind` (`"health"` or `"resource"`; missing means health) and `playerThresholdPercent` (whole percentage 1–100; missing means 70, `false` ignores the trigger), `requireLivingTarget` (`true` hides player, pet, and target frames for a dead or ghost target outside edit mode; missing means off), `groupAuras` (`false` leaves buffs and debuffs on their own; missing means on), `alwaysShowDebuffs` (`false` lets debuffs follow the usual aura fade rules; missing means on), `chat` (`false` turns modern chat off; missing means on), `chatFade` (seconds a modern-chat line stays at the bottom; missing means 10, `0` keeps it), `groups` (fade group per bar; a missing key keeps the default below), `hostile` and `friendly` (bar ids that stay up while the target is alive and can be attacked, or is friendly; a missing key means off), `range` (`yards` is `10`, `28`, or `"spell"`, `kind` is `"hostile"` or `"friendly"`, and `spell` is an optional spell name; a missing `spell` means the longest matching spell on bar 1; a missing `range` means off), `autoHideParty` (`true` fades party/raid frames while exploring; missing means off), and `previousLayout` (the Edit Mode layout index that was active before QuietUI, kept even while force is off). No sliders and no libraries like Ace3.
- Presets share all setup settings except forceLayout, which is only for <no preset>. Save commits selection, creation, rename, layout and settings together. Choosing a preset layout previews it immediately, including while disabled; combat defers the switch. X/Escape cancel the preview and restore its original layout. Save keeps the preview and preserves the layout to restore on disable. Delete requires confirmation and is immediate. Missing/deleted presets detach to the last personal snapshot. Reset detaches and saves defaults without changing the shared preset. A preset selects its linked layout on login, enable and Save; missing layouts fall back to QuietUI with one warning per session and retain the invalid link for repair. Disable restores the previous layout.
- Player-facing text (chat, tooltip) is English.

## Look

- Flat, dark, thin border. Background `0.05, 0.05, 0.05, 0.75`, border `0.85, 0.85, 0.85, 0.35`, highlight `0.95, 0.75, 0.25`.
- The setup window uses the game character frame: gold border, player portrait, and the game's checkboxes and buttons. When that frame template is missing, it uses the gold dialog, then the flat border.
- Message prefix: `|cff8fd4c8QuietUI|r`.
- A short friendly greeting on login and reload: the state, then one short line each for `/quiet` and `/quiet setup` so commands never wrap. No other chat messages unless the player acts or something fails.
- Visible has mutually exclusive Always visible and Only on hover checks per HUD row; action bars and swing timer are configured only in Bars and Groups. Bars holds per-bar Enemy, Friend and Group. Groups holds a scrollable Group visibility section with one row per used group, its members, and mutually exclusive Always visible and Only on hover checks. The setup window is compact and keeps one height across tabs. General selectors span its content width and its preset buttons are evenly spaced. With both checks off, the usual rules apply. Group modes disable Enemy/Friend without clearing their values. Only on hover overrides combat, vehicle, instance, group, target, low health/power, XP reward and post-combat timer rules. It also overrides aura grouping and Always show debuffs. Glance and Edit Mode still reveal these frames; bars and XP also show with an open spell flyout or an item on the cursor. Bag slots, dragging and cursor items keep the bag button up. Cooldowns, meter and resource gain independent hover catchers on UIParent; disable hides these and restores alpha. Settings share through presets; Reset clears custom modes and defaults XP to Only on hover. Legacy visible.bars and visible.swing pins migrate to group modes, splitting mixed groups to preserve visibility. A checked row under Always visible stays visible and skips the fade below. Unchecked rows keep it. The player frame check turns the portrait and pet on beside the resource bar, and they still fade.
- Action bars fade in groups. A faded frame appears at once and fades out over 0.3 s. Hover shows the whole group from the bar rectangle, including empty slots. A filled button stays above that rectangle, so its tooltip and click still land on the spell. The default is bars 1–3 with the stance bar, the pet bar and the totem bar, bars 4–5, and each later bar on its own. The swing timer is group 10. The same number in `/quiet setup` fades together. Combat, a vehicle, edit mode, an instance (party, raid, pvp, arena), an open spell flyout, or an item on the cursor shows every group. Always visible in Group visibility keeps the entire selected group up, including the swing timer if it belongs to that group. Only on hover uses hover of any member to reveal the entire group. Enemy and Friend on a bar row keep that bar up while the target is alive and can be attacked (`UnitCanAttack`, and not `UnitIsDeadOrGhost`) or is friendly (`UnitIsFriend`), including out of combat. They do not show the rest of the fade group. A missing flag means off. The XP bar defaults to Only on hover, with Glance, Edit Mode, spell flyout and cursor-item exceptions. Unchecking Only on hover restores the usual bar triggers: combat, a vehicle, an instance, hover, Edit Mode, flyout and cursor items, plus 5 s after a quest turn-in that gives XP. Always visible keeps it up.
- Party and raid frames keep Blizzard visibility by default. Visible adds Party and raid frames with Always visible checked when `autoHideParty` is missing or false. Unchecking enables autohide; Only on hover is disabled for this row. Combat, an instance, hover over any member or the block gaps, Glance, and Edit Mode reveal the entire block immediately. Otherwise it fades out over 0.3 s. Target selection and group membership alone do not reveal it. Fade only outer containers so nested frames do not fade twice. Descendant frames and textures that ignore parent alpha, including selection highlights, fade independently and restore their saved alpha. Hover catchers live on UIParent and do not intercept clicks. Save shares through presets; Reset restores Always visible. The portrait, pet, auras, and raid manager keep their own rules.
- The cooldown manager shows only in combat, in an instance, in a group, or in edit mode. Hover does not show it.
- The damage meter behaves the same and stays for 10 s after combat.
- The personal resource bar shows only in combat, in an instance, or in edit mode, and anywhere while mana, focus, or energy is below 70 %. Its health bar also shows anywhere while health is not full. Hover does not show it. It appears at once and fades out over 0.3 s.
- The player frame (`PlayerFrame`) is on unless setup sets `player` to `resource`. Off, it shows only in edit mode. On, it shows with a target, in combat, in an instance (party, raid, pvp, arena), in a group, in a vehicle, on hover, and while Glance is on. It also shows below one selected threshold: Health or Resource (mana, focus or energy), default Health below 70%. An empty Percent input ignores this trigger; the threshold does not restrict combat, instance or the other usual show rules. The selector and input are shown only while Player frame is on, retain their values while off, and save through presets. Percentages must be whole numbers from 1 to 100; exactly at the threshold does not trigger visibility. Rage and the other powers that rest at zero do not. A pet being out does not keep it up. `PetFrame` follows the same visibility rules. Death or ghost form hides only `PlayerFrame`, overriding all ordinary triggers and the selected threshold. Numeric alpha fades over 0.3 s; an unreadable secret alpha clears immediately without revealing a previously hidden portrait. Glance and Edit Mode bypass this death rule while preserving the existing player-off and dead-target rules. Pet, auras, and the personal resource bar keep their usual behavior; an inherited pet is isolated from portrait alpha and its original inheritance is restored on disable. If pet alpha isolation is unavailable, the portrait and inherited pet retain their usual rules; missing or failing isolation APIs report once. It appears at once and fades out over 0.3 s. The personal resource bar keeps its own rules. Player setup also offers Require a living target (default off). When on, a dead or ghost target fades the player, pet, and target frames even in combat, on hover, or during Glance. The selected health/resource threshold overrides this block for the player and pet only; the dead target frame stays faded. An empty threshold or Player frame off grants no override. Edit mode still shows them. With a living target, no target, or the option off, the usual rules apply and Blizzard controls the target frame.
- In range is off unless setup checks it. Checked, a green gradient fills the health bar on the target's nameplate while that target is alive and in range. It is strong on the left (`0.15, 0.82, 0.22` at `0.9`) and fades toward the right (`0.55, 0.95, 0.4` at `0.15`), so the bar still shows through. Always visible action bar groups do not block it. Combat, a vehicle, an instance, Edit Mode, an open spell flyout, an item on the cursor, and Glance skip it, and the distance is not read in those cases. It does not show action bars. The plate comes from `C_NamePlate.GetNamePlateForUnit("target")` (or `GetNamePlateForUnit`). The gradient prefers the short health bar inside the plate, not the tall click area, and is parented to that bar, because a nameplate has no screen rectangle to copy. When the gradient hides it returns to `UIParent`. The nameplate's alpha is never changed. Within is 10 yards (`CheckInteractDistance` trade), 28 yards (inspect), or Spell. Spell uses `IsSpellInRange` on the name in the Spell field. An empty Spell field uses the longest harmful or helpful spell on bar 1, read with `IsActionInRange`. Unfriendly keeps a harmful spell, so a neutral the spell can hit still counts when `UnitCanAttack` is false. Friendly keeps a helpful spell and a reaction of 5 or higher. A dead target does not count. Only `target`. With no nameplate on screen the gradient stays down. It appears at once and fades out over 0.3 s. The distance is read every frame, so walking into range does not wait on focus. Glance and combat do not turn it on. Always visible group modes do not affect it. A missing `range` means off. A secret range result is left as it was.
- The quest tracker (`ObjectiveTrackerFrame` / `QuestWatchFrame`) shows only on hover or in edit mode. Hover is the whole rectangle, including the gaps between quests. An invisible catcher on `UIParent` follows that rectangle. It is not a child of the tracker, so a faded tracker does not drop the mouse, and it does not take clicks. It appears at once and fades out over 0.3 s.
- Debuffs (`DebuffFrame`) always stay visible while QuietUI is enabled unless Player setup unchecks Always show debuffs (`alwaysShowDebuffs`, missing means on). This overrides aura grouping and player frame visibility without revealing buffs or the portrait. With this option off, they follow the same rules as buffs below.
- Buffs and optional fading debuffs (`BuffFrame`, `DebuffFrame`, `TemporaryEnchantFrame`) show only in combat, in an instance, in a group, on hover, or in edit mode. With `groupAuras` on they also show while the player frame is visible, including its selected health or resource trigger while the player frame is on. The portrait death rule does not change these aura triggers. With the player frame off, grouping does not pull them up. They appear at once and fade out over 0.3 s.
- Bags collapse into one button. The button shows only on hover, while bag slots are shown, while an item is on the cursor, or while dragged. Left click opens bags, right click shows the bag slots for swapping, drag moves it. It does not open the micro menu.
- The micro menu shows on hover (the whole row, including the gaps), in edit mode, or while Glance is on. It appears at once and fades out over 0.3 s. A checked row under Always visible holds it. Combat, an instance, and a group do not show it.
- Press `` ` `` (Glance) to show the faded HUD at once: every action bar, the XP bar, the cooldown manager, the damage meter, the personal resource bar (health and power), the quest tracker, buffs and debuffs, the bag button, and the micro menu. The portrait and pet show only when the player frame is on. Press again and the rules above apply, including a checked row. The state is not saved, and turning QuietUI off clears it. Chat is unchanged and the addon does not toggle. The binding is `QUIETUI_GLANCE`, category `QUIETUI` (shown as QuietUI). Do not set `header` on it: the client turns that into a bindable row named `HEADER_QUIETUI` under Other. `SetBinding` applies `` ` `` when that key is free or still on `HEADER_QUIETUI`, and leaves any other action alone. The key can be changed in Key Bindings. Only the key-down arrives as a toggle; key-up is ignored.
- The addon ships an Edit Mode layout named `QuietUI`. `LayoutString.lua` is the source of truth. Each new version of the string is offered once in the addon's own prompt. It uses the same character frame as setup, with a gear icon instead of the player portrait (the flat border when that template is missing; not `StaticPopup`, which spreads taint). The answer (add, update, or not now) is remembered as a hash in `QuietUIDB.layoutHash`; saved layouts are never compared, because the client rewrites them. An updated layout is replaced in place only after the player agrees. With Force QuietUI layout on, turning QuietUI on selects the QuietUI layout and creates it from that string when it is missing. The layout that was active before is stored per character as `previousLayout` and selected again when QuietUI is turned off. With no preset and force off, enable, disable, login, and reload leave the active layout alone. An active preset uses its existing layout instead of forcing QuietUI; when its layout is missing the bundled layout is created only if needed. Use `C_EditMode` only, never `EditModeManagerFrame` methods (taint).
- Chat keeps its text and drops the chrome while Modern chat is on (the default). Each line is a translucent black bubble; a new line slides in from the left and older lines ease upward. At the bottom, a line fades across its last half second and drops after the fade interval (10 s unless setup says otherwise; 0 keeps it). The lines stay in the list, so scrolling still walks the full history. Hovering the chat block shows the lines that fit in the window, including ones that already faded, and the wheel works on that whole block. Leaving it fades back to the bottom view. Hover a line to copy it. A numbered channel shows only its number, and guild, party, raid and the other group tags use a short letter. Joining, leaving, or changing a channel is not shown. Money and experience follow the chat tab filters (Experience and Currency). Loot stays. The input is a flat field, visible at once while focused, and it fades out when it loses focus. Enter stays a Blizzard binding. Turning Modern chat off leaves the original chat untouched.

- `/quiet glance` toggles Glance through the same function as its key binding, for use in macros and controller setups. It does nothing while QuietUI is off, does not toggle the addon, and does not save the Glance state.
- `/quiet preset` lists the current and available shared presets. `/quiet preset "name"` selects an existing preset by case-insensitive name, saves its personal snapshot and applies the usual preset layout rules without changing enabled state. Combat defers the layout; while disabled, selection waits for enable. Missing or ambiguous names only print an English error. A successful selection cancels any setup draft and layout preview and refreshes the open setup window.
- The layout selector filters built-in and saved layouts by the client's `interfaceStyle` and current input interface mode. Missing style means keyboard and mouse. Named layout references include `interfaceStyle` to distinguish matching names across modes; filtering never changes the absolute Edit Mode indices.
- Shared presets hold an `interfaceStyle` tag derived from their linked layout on Save. Legacy presets derive and save the tag from layout metadata. The shared preset selector and slash list filter by the current mode, and slash commands and activation reject incompatible presets before changing settings or previews.
- Login/reload validates the selected preset's layout interface once, waiting for layout data if needed and before selecting a layout. An incompatible preset detaches to its personal snapshot without modifying the shared preset or switching the active layout. Missing layouts retain the existing fallback behavior.

## Client

- WoW Forever beta, `Interface: 16001`. The API mixes classic and newer frames; a global may not exist.
- The main bar is `MainActionBar`, not `MainMenuBar`. In gamepad mode the bars live under `GamepadMainActionBarFrame` (load-on-demand `Blizzard_GamepadActionBars`). The damage meter is a Blizzard load-on-demand addon; its frames are found by the `DamageMeter` prefix. The cooldown manager is `EssentialCooldownViewer`, `UtilityCooldownViewer`, `BuffIconCooldownViewer`, `BuffBarCooldownViewer`. The personal resource bar is `PersonalResourceDisplayFrame`; do not fade nameplates, they are recycled across units.
- Unit health and power are secret values, even out of combat. Never compare them or do math on them; pass them to widgets (for example `UnitPowerPercent` with a `C_CurveUtil` curve into `SetAlpha`). Check with `ns.IsSecret`.
- Scans of `UIParent` children can hit forbidden frames. Check `ns.Usable` before calling any method.
- Wrap calls that may be missing on this client in `pcall`, or check `type` first.
- An unknown event in `RegisterEvent` throws. Register each event separately inside `pcall`.
- Print each error once through `Report`.

## Touching the UI

- Action bars only through alpha. Do not use `Hide()`, `Show()`, or state drivers on bars.
- No secure snippets. Do not touch `ChatFrame_OpenChat`.
- `PlayerFrame` and `PetFrame` only through alpha, per the rule above. TargetFrame may only be faded through alpha for Require a living target. Party and raid frames may only be faded through alpha for the optional autohide rule above. Do not hide the minimap, vehicle / extra action / zone ability, or the LFG eye (`QueueStatus`, `LFGEye`).
- Blizzard overwrites alpha. Hold the wanted value with a `SetAlpha` hook and the `_quietApplying` flag so the hook does not loop.
- Disabling must restore saved alpha and textures (`RestoreAll`). Wire new behavior into both `ApplyAll` and `RestoreAll`.

## Code

- Files load in `QuietUI.toc` order and share the addon table: `local _, ns = ...`. No globals except `QuietUIDB`, `QuietUICharDB`, the slash command, `QuietUISetup` so Escape can close the setup window, and `QuietUIGlance`, `BINDING_CATEGORY_QUIETUI`, and `BINDING_NAME_QUIETUI_GLANCE` for the Glance key. Do not add libraries.
  - `Core.lua`: `DB`, `Print`, `Report`, alpha hooks, fading, texture hiding, restore.
  - `Presets.lua`: shared preset CRUD, effective settings, and personal snapshots.
  - `Frames.lua`: bar / bag / spared classification, `Mute`.
  - `Bars.lua`: action bars, `ShowAll`, and `BarTarget`.
  - `Faders.lua`: XP bar, cooldown manager, damage meter, player frame, pet frame, quest tracker, buffs, and the range gradient.
  - `Menu.lua`: the bag button and the micro menu fade.
  - `Chat.lua`: chat chrome, line bubbles, and the input box.
  - `LayoutString.lua`: only the Edit Mode export string. Update it by pasting a new export.
  - `Layout.lua`: asks to add or update the `QuietUI` Edit Mode layout from that string.
  - `Setup.lua`: the `/quiet setup` window, `CharDB`, `Pinned`, `PlayerStyle`, `GroupAuras`, `AlwaysShowDebuffs`, `ChatFade`, `Range`.
  - `QuietUI.lua`: `ApplyAll`, `RestoreAll`, events, `OnUpdate`, `/quiet`.
- Call other files through `ns` at run time, not through locals captured at load, so load order only matters for `QuietUI.lua` being last.
- Comments in English, short, only where the reason is not visible from the code.
