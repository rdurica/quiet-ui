# Saved settings

What `QuietUIDB` (account) and `QuietUICharDB` (character) may hold, with defaults.

- `QuietUIDB` is the account and may hold only `enabled`, the button position after dragging, `layoutHash` (the last answered layout version), `welcomed` (the first-run welcome was answered or skipped; missing shows it on a fresh install), `presets` (stable IDs to named shared settings and layout references), `nextPresetId` (monotonic ID counter), `minimap` (degrees around the minimap for the setup button; a missing value sits at the bottom-left), `setupPoint` (`{ point, relativePoint, x, y }` of the setup window after dragging its header; missing means centred), `highlightCVars` (the original values of the six soft-target CVars while Highlights holds them; missing means nothing to restore), and `lastProfile` (the lines of the last `/quiet profile` result, every section, so it can be read after `/reload`). The setup is per character in `QuietUICharDB`: `presetId` (missing means <no preset>), `previousLayoutRef` (name and type, or built-in identity, for restoring after layout reordering), `presetLayoutManaged` (a preset took over the layout; restore it even after detaching), and a personal snapshot of the settings (also `windowPoints`, kept for this character only: not in presets and not cleared by Reset default; Reset positions on the Modern tab clears it immediately without changing other settings; it maps a window key to `{ point, relativePoint, x, y }` saved when a Modernize window is dragged): `visible` (HUD rows that stay on screen; excludes action bars and swing timer; a missing flag means off), `hoverOnly` (HUD rows that show only on hover; missing means off except XP, which defaults on unless Always visible is set; explicit false keeps normal XP rules), `groupVisibility` (numeric fade-group IDs to `"always"` or `"hover"`; missing means usual rules), `forceLayout` (`true` selects the QuietUI layout when the addon turns on and restores the previous one when it turns off; missing means off), `player` (`resource` keeps the portrait for edit mode; missing means on, beside the personal resource bar), `playerThresholdKind` (`"health"` or `"resource"`; missing means health) and `playerThresholdPercent` (whole percentage 1–100; missing means 70, `false` ignores the trigger), `requireLivingTarget` (`true` hides player, pet, and target frames for a dead or ghost target outside edit mode; missing means off), `groupAuras` (`false` leaves buffs and debuffs on their own; missing means on), `alwaysShowDebuffs` (`false` lets debuffs follow the usual aura fade rules; missing means on), `questNotice` (`false` turns quest update notices off; missing means on), `questNoticeSize` (`"smaller"` or `"larger"`; missing means the tracker size), `highlights` (`herb`, `ore`, `quest` set to `true` glow that soft-interact category; only true values are stored, missing means off), `questMobs` (`false` turns quest mob icons off; missing means on), `chat` (`false` turns modern chat off; missing means on), `chatTabs` (`"top"` keeps the chat tabs above the chat; missing means below it), `chatFade` (seconds a modern-chat line stays at the bottom; missing means 10, `0` keeps it), `groups` (fade group per bar; a missing key keeps the default below), `hostile` and `friendly` (bar ids that stay up while the target is alive and can be attacked, or is friendly; a missing key means off), `range` (`yards` is `10`, `28`, or `"spell"`, `kind` is `"hostile"` or `"friendly"`, and `spell` is an optional spell name; a missing `spell` means the longest matching spell on bar 1; a missing `range` means off), `autoHideParty` (`true` fades party/raid frames while exploring; missing means off), `modernize` (a table, shared through presets, Reset clears it; see [modern.md](modern.md): `enabled` `true` turns Modernize on, missing means off; `theme` a theme name, missing or unknown means `"dark"`; `xpGain` `false` turns Show on big XP gain off, missing means on; one `<area key>` `false` per registered area turns that area off, missing means on), and `previousLayout` (the Edit Mode layout index that was active before QuietUI, kept even while force is off). No sliders and no libraries like Ace3.
