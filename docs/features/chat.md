# Chat

The Chat tab of `/quiet setup`, shown while the Chat module is on (see [modules.md](modules.md)): Modern chat and chat input history. There is no separate Modern chat checkbox; the module is the switch. The tab keeps the fade time and the Tabs choice (`chatFade`, `chatTabs`).

- Chat keeps its text and drops the chrome while the Chat module is on. Each line is a translucent black bubble; a new line slides in from the left and older lines ease upward. At the bottom, a line fades across its last half second and drops after the fade interval (10 s unless setup says otherwise; 0 keeps it). The lines stay in the list, so scrolling still walks the full history. Hovering the chat block shows the lines that fit in the window, including ones that already faded, and the wheel works on that whole block. Leaving it fades back to the bottom view. Hover a line to copy it: only the message is copied, without the time, channel tag or sender; a line without a sender (loot, system, emote) loses only the time and channel tag. A secret line (player chat in an instance) cannot be measured: its bubble follows the height of its text and spans the chat width, and the lines above rest on its top edge (they move with it, without easing, when a newer line arrives below it); hovering it reads as not hovered, so it has no copy icon. A numbered channel shows only its number, and guild, party, raid and the other group tags use a short letter. Joining, leaving, or changing a channel is not shown. Money and experience follow the chat tab filters (Experience and Currency). Loot stays. The input is a flat field, visible at once while focused, and it fades out when it loses focus; while unfocused it does not take clicks, so they reach the tabs. Enter stays a Blizzard binding. By default the chat tabs sit below the chat, under the strip where the input appears; with Tabs set to Top (`chatTabs`) they keep Blizzard's own points above the chat. Either way they are hidden until the mouse is over the chat or the tab row. The tab row counts as hovering its chat, so clicking a tab shows that window's lines at once; a tab that flashes for new messages stays visible on its own. Chat and tab hover is read again when the pointer moves, and otherwise at most every 0.1 s. Whisper tabs that open their own temporary window get the same Modern chat treatment. When Tabs is Bottom and there is no room above the screen bottom, they stay at the bottom edge and the input covers them while you type. Turning the Chat module or QuietUI off puts the tabs back at Blizzard's points and leaves the original chat untouched.
- The chat input remembers what you send. Alt+Up and Alt+Down walk the last 50 sent lines and commands; the lines are kept per character and come back after reload and relog. A line sent from one chat window is offered in every window's input. It follows the Chat module only. Apply gives the inputs room for 50 lines and fills them with the stored lines; restore (QuietUI off) gives back the old line limit, keeps the stored lines and stops adding new ones.
