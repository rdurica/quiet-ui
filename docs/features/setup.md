# Setup window

The `/quiet` command, the `/quiet setup` window, its look, and chat messages.

- `/quiet` turns it on or off (`on` / `off`, no argument toggles). `/quiet setup` is the one window, with eight tabs: General, Visible, Bars, Groups, Player, Misc., Modern, and Info. Info holds a short description of QuietUI and how Glance works. General holds shared presets and their existing Edit Mode layouts, or Force QuietUI layout for <no preset> (missing means off). Check what stays visible, set which bars fade together, choose which bars stay up for an enemy or a friendly target, turn the player frame on or off, group buffs and debuffs with that frame (missing means on), keep debuffs always visible (missing means on), turn In range on or off, choose 10 yards, 28 yards, or Spell, type an optional spell name, and choose Unfriendly or Friendly, choose modern chat and how soon its lines fade, turn quest updates on or off, choose Highlights for herbs, ore, and interact objects, turn Quest mobs on or off, choose Modernize and its options (see [modern.md](modern.md)); Reset positions there clears saved Modern window positions immediately, independently of Save; then Save, which leaves the window open. Reset default restores the rules below, turns force off, and saves immediately. Import layout writes the bundled Edit Mode layout right away, even after "Not now". The X and Escape close the window without saving. The window stays the size of the tallest tab, so switching tabs does not resize it. A minimap button toggles that window. Left click opens or closes it even while QuietUI is off; closing cancels unsaved changes and layout previews like X or Escape. Drag moves it around the minimap.
- The setup window wears the same chrome Modernize draws on Blizzard's windows, whether Modernize is on or not, so it reads as part of the game: the theme background, opaque and lit towards the top, a quiet outline, and a 24 px header band (theme `strip`, lit towards the top) over the accent hairline, with the centred title and a bare close cross that turns the theme danger red under the mouse. Dragging the header band moves the window (clamped to the screen); the point is kept account-wide in `QuietUIDB.setupPoint` and used on every open, also after a reload. Without a saved point it opens centred. The tabs are a sidebar on the left that sinks a step below the panel, like a window inset; the selected tab is a strip with a 2 px accent mark and an accent label, the others grey text. The window is 940 px wide. Pages sit right of the sidebar, 700 px wide; the actions sit in a footer under them, Reset default and Import layout on the left and Save, edged and labelled in the accent, on the right. Section titles are Modernize's section headers: an accent title on a strip with the accent mark, which also carries a table's column titles; Misc. and Modern use two columns, the Visible, Bars and Player tables one, with a faint band on every other row of Visible and Bars. Buttons and steppers have the panel fill and a thin grey edge; fields and checkboxes the dark theme track, an accent mark when checked, and an accent edge on the field being typed in or the checkbox under the mouse. Buttons, tabs and menu entries show a faint white wash under the mouse; selectors show a chevron and their chosen entry is a strip like the selected tab; the Groups list scrolls with bare accent chevrons. Text uses the regular game font size; notes are grey. The preset dialog, the selector menus and the layout prompt use the same window (the prompt has no close, only its two buttons answer). Edges and fills are textures, so the look does not depend on `BackdropTemplate` or Blizzard templates.
- Message prefix: `|cff8fd4c8QuietUI|r`.
- A short friendly greeting on login and reload: the state, then one short line each for `/quiet` and `/quiet setup` so commands never wrap. No other chat messages unless the player acts or something fails.
- Player-facing text (chat, tooltip) is English.
