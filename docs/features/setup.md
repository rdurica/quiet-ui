# Setup window

The `/quiet` command, the `/quiet setup` window, its look, and chat messages.

- `/quiet` turns it on or off (`on` / `off`, no argument toggles). `/quiet setup` is the one window, with nine tabs: Modules, General, Visible, Bars, Groups, Player, Chat, Helpers, Modern, and Info. Modules is first and holds the five module checkboxes (see [modules.md](modules.md)). The sidebar lists only the tabs of modules that are on in the draft: Visible, Bars, Groups and Player belong to Fading, Chat to Chat, Helpers to Helpers, Modern to Modernize; Modules, General and Info always show. Unchecking a module hides its tabs at once; an open page whose tab leaves falls back to Modules; X and Escape restore the saved tabs. Info holds a short description of QuietUI and how Glance works. General holds shared presets and their existing Edit Mode layouts, or Force QuietUI layout for <no preset> (missing means off); with Layout off the layout selector, Force QuietUI layout and Import layout are not shown. Check what stays visible, set which bars fade together, choose which bars stay up for an enemy or a friendly target, turn the player frame on or off, group buffs and debuffs with that frame (missing means on), keep debuffs always visible (missing means on), turn In range on or off, choose 10 yards, 28 yards, or Spell, type an optional spell name, and choose Unfriendly or Friendly, choose how soon chat lines fade and where the tabs sit, turn quest updates on or off, choose Highlights for herbs, ore, and interact objects, turn Quest mobs on or off, choose the Modern theme and areas (see [modern.md](modern.md)); Reset positions there clears saved Modern window positions immediately, independently of Save; then Save, which leaves the window open. Save with a changed module set restores everything, saves and reloads the UI (the reload is a secure `/reload` macro armed by the click itself, out of combat only, so combat starting while the window is filled in cannot run it; a new Modernize look saved in combat applies in place and chat asks for `/reload`); with no module checked it prints `Choose at least one module, or turn QuietUI off with /quiet off.` and saves nothing; in combat it refuses a module change and prints `Leave combat to change modules.`. Reset default restores the rules below, turns force off, and saves immediately; when that changes the module set it reloads the UI, and in combat it refuses and prints `Leave combat to change modules.`. Import layout writes the bundled Edit Mode layout right away, even after "Not now". The X and Escape close the window without saving. The window stays the size of the tallest tab, so switching tabs does not resize it. A minimap button toggles that window. Left click opens or closes it even while QuietUI is off; closing cancels unsaved changes and layout previews like X or Escape. Drag moves it around the minimap.
- The setup window wears the same chrome Modernize draws on Blizzard's windows, whether Modernize is on or not, so it reads as part of the game: the theme background, opaque and lit towards the top, a quiet outline, and a 24 px header band (theme `strip`, lit towards the top) over the accent hairline, with the centred title and a bare close cross that turns the theme danger red under the mouse. Dragging the header band moves the window (clamped to the screen); the point is kept account-wide in `QuietUIDB.setupPoint` and used on every open, also after a reload. Without a saved point it opens centred. The tabs are a sidebar on the left that sinks a step below the panel, like a window inset; the selected tab is a strip with a 2 px accent mark and an accent label, the others grey text. The window is 940 px wide. Pages sit right of the sidebar, 700 px wide; the actions sit in a footer under them, Reset default and Import layout on the left and Save, edged and labelled in the accent, on the right. Section titles are Modernize's section headers: an accent title on a strip with the accent mark, which also carries a table's column titles; Chat, Helpers and Modern use two columns, the Visible, Bars and Player tables one, with a faint band on every other row of Visible and Bars. Buttons and steppers have the panel fill and a thin grey edge; fields and checkboxes the dark theme track, an accent mark when checked, and an accent edge on the field being typed in or the checkbox under the mouse. Buttons, tabs and menu entries show a faint white wash under the mouse; selectors show a chevron and their chosen entry is a strip like the selected tab; the Groups list scrolls with bare accent chevrons. Text uses the regular game font size; notes are grey. The preset dialog, the selector menus and the layout prompt use the same window (the prompt has no close, only its two buttons answer). Edges and fills are textures, so the look does not depend on `BackdropTemplate` or Blizzard templates.
- Welcome: once per character, also after an update, a window in the same chrome, without a close, offers Classic (Chat, Fading, Helpers and Layout on, Modernize off) or Modern (all five on), each a card with a screenshot and one line, and under them a full-width Custom choice, and a grey note that everything can be changed later in `/quiet setup`. Clicking a card selects it (accent edge); one Choose button answers. Custom opens a second screen in the same window with the five module checkboxes (only Chat checked), a Back button to the cards, and Save, disabled while nothing is checked; Save writes the checked set, marks the character welcomed and reloads the UI. In combat Custom Save refuses and prints `Leave combat to change modules.`. On a fresh install no card is selected and Choose waits for one; a character that already uses QuietUI (the account answered a layout prompt, Modernize is on, or a preset is active) sees its current look selected (Modern when Modernize is on, Classic for the Classic set, no card for any other set). The choice is written to the current settings; with an active preset that is the shared preset, and the note names it. A changed look reloads the UI at once; the same look only closes the window. In combat the reload is not possible, so the choice is saved and chat asks for `/reload`. `QuietUICharDB.welcomed` keeps it from showing again on that character. The layout prompt waits until the welcome is answered, and does not come at all when the chosen set has Layout off.
- `/quiet dump` opens the report window (named `QuietUIDump`, closed by its cross or Escape, centred, dragged by its header, no saved point; works in combat): two numbered steps. Step 1: the issue link field, focused with its text selected on open; the link opens the bug issue form with `Setup` prefilled (version, client, interface mode, preset, modules). Step 2: the read-only report box. Interface mode follows the UI interface style (gamepad or mouse and keyboard). Clicking a field selects all its text again; typing changes nothing. Each open rebuilds the report and saves it in `QuietUIDB.lastDump`. While QuietUI is off it prints `QuietUI is off. Turn it on with /quiet on, then type /quiet dump.` and opens nothing. The once-per-error chat message ends with `Type /quiet dump to report it.`. Actions of QuietUI blocked or forbidden by the client (`ADDON_ACTION_BLOCKED`, `ADDON_ACTION_FORBIDDEN`) are reported the same way, also while QuietUI is off, without a stack. Each error line also shows combat, instance and group from its first occurrence. Sent chat lines are never in the report; the Settings section shows only their count. The Info tab says: `Found a bug? Type /quiet dump and send the report.`
- Message prefix: `|cff8fd4c8QuietUI|r`.
- A short friendly greeting on login and reload: the state, then one short line each for `/quiet` and `/quiet setup` so commands never wrap. No other chat messages unless the player acts or something fails.
- Player-facing text (chat, tooltip) is English.
