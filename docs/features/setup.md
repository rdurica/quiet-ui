# Setup window

The `/quiet` command, the `/quiet setup` window, its look, and chat messages.

- `/quiet` turns it on or off (`on` / `off`, no argument toggles). `/quiet setup` is the one window, with seven tabs: General, Visible, Bars, Groups, Player, Misc., and Info. Info holds a short description of QuietUI and how Glance works. General holds shared presets and their existing Edit Mode layouts, or Force QuietUI layout for <no preset> (missing means off). Check what stays visible, set which bars fade together, choose which bars stay up for an enemy or a friendly target, turn the player frame on or off, group buffs and debuffs with that frame (missing means on), keep debuffs always visible (missing means on), turn In range on or off, choose 10 yards, 28 yards, or Spell, type an optional spell name, and choose Unfriendly or Friendly, choose modern chat and how soon its lines fade, turn quest updates on or off, choose Highlights for herbs, ore, and interact objects, turn Quest mobs on or off, turn Parchment windows on or off (missing means off), then Save, which leaves the window open. Reset default restores the rules below, turns force off, and saves immediately. Import layout writes the bundled Edit Mode layout right away, even after "Not now". The X and Escape close the window without saving. The window stays the size of the tallest tab, so switching tabs does not resize it. A minimap button toggles that window. Left click opens or closes it even while QuietUI is off; closing cancels unsaved changes and layout previews like X or Escape. Drag moves it around the minimap.
- The setup window uses the game character frame: gold border, player portrait, the game's checkboxes and buttons, and small gold-edged controls. Missing button templates use a dark fallback with thin borders. Setup, preset dialogs, selector menus, and the layout prompt have an opaque dark background; the active tab uses the gold highlight. When that frame template is missing, it uses the gold dialog, then the flat border.
- Flat, dark, thin border. Background `0.05, 0.05, 0.05, 0.75`, border `0.85, 0.85, 0.85, 0.35`, highlight `0.95, 0.75, 0.25`.
- Message prefix: `|cff8fd4c8QuietUI|r`.
- A short friendly greeting on login and reload: the state, then one short line each for `/quiet` and `/quiet setup` so commands never wrap. No other chat messages unless the player acts or something fails.
- Player-facing text (chat, tooltip) is English.
